# SecuraLog | Laboratorio de Git y seguridad

**Proyecto completamente ficticio.** No contiene credenciales activas.

Aplicacion de ejemplo y repositorio con historial de desarrollo, ramas y configuraciones.
Objetivo: utilizar Git desde terminal y GitHub para revisar cambios y localizar evidencias.

En la rama principal y en una rama de pruebas existen tres pistas con formato `LABFLAG{...}`.
No es necesario instalar dependencias ni ejecutar la aplicacion.

> Los tokens y contrasenas se han inventado para docencia. No usarlos para autenticar ante ningun servicio.
